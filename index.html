Planificador de entrenamiento

Las cargas del repositorio representan tu carga de referencia a RIR 2. Si una carga cambia, actualízala allí antes de generar la siguiente sesión.

Repositorio de ejercicios

Los ejercicios están bloqueados para evitar cambios accidentales. Pulsa ✎ para editar uno. Los tags indican qué músculos o zonas trabaja y se usan para encontrar alternativas equivalentes.

Criterios de programación

  • RIR 2 es la referencia del repositorio; la sesión puede acercarse a RIR 1 en series pesadas de días altos.
  • Las series pesadas se reservan sobre todo para ejercicios compuestos principales. Los aislamientos no reciben automáticamente una subida de carga.
  • La duración modifica el número de ejercicios/series. La intensidad modifica volumen y proximidad al fallo.
  • Torso permite trabajar pecho, espalda, hombros, bíceps, tríceps y core sin incluir ejercicios de piernas.
  • Los ejercicios con carga “?” se muestran como no calibrados y no reciben una carga inventada.
  • La prioridad A–E solo se usa para la selección inicial: primero se respeta el reparto entre grupos y, dentro de cada grupo, se priorizan A, después B, C, D y E. Entre ejercicios con la misma letra se busca variedad de músculos mediante los tags.
    A = Ejercicio fundamental. Aunque haya poco tiempo, hay que hacerlo.
    B = Ejercicio importante. En una sesión normal tiene que estar sí o sí.
    C = Ejercicio complementario. Con algo más de tiempo puede tener un hueco en el entrenamiento.
    D = Ejercicio residual. Salvo que haya mucho tiempo o poca alternativa, no debería de estar presente.
    E = Ejercicio prescindible. Solo si no hay alternativa en el grupo muscular para el tiempo disponible.
  • Las alternativas de “Otra opción” no dependen de la prioridad: solo se ofrecen ejercicios del mismo grupo con exactamente el mismo perfil de tags y que no estén ya en la sesión.
  • Nunca se repite el mismo ejercicio dentro de una sesión.
